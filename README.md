# Ubuntu for kindle
Ubuntu shell for kindle.

# Prerequistes
armhf jailbroken kindle
Computer to transfer files from
KTerm
# Installation
Download latest release

copy ubuntu folder (make sure no nested folders) to /mnt/us
(you can also replace the ext4 with one of yours)
# Usage
to open type "sh /mnt/base-us/ubuntu/ubuntu.sh" in kterm
or copy the booklet in master to documents
IDK what to use it for
# Other information
armhf only
Currently I haven't figured out how to get a gui so it is only a shell.

I used chatgpt to generate ext4
